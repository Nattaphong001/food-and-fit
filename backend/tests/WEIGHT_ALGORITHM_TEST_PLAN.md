เตรียมเมื่อ 2026-09-20 · อ้างอิงบทที่ 2 ข้อ 2.1.4.12 · โค้ดที่ทดสอบ: `backend/services/calculator.go`
ค่า "ที่ควรได้" ทุกตัวคำนวณมือจากสเปก **ไม่ได้ดึงจากโค้ดระบบ** ผลรันจริงอยู่ที่ `RESULT_2026-09-20_weight_algorithm_steps.md`

## 0. ตั้งค่าก่อนทดสอบ

- น้ำหนักตัวของสมาชิก **70 กก.** (ตารางด้านล่างคำนวณที่ 70 กก. — ถ้าใช้น้ำหนักอื่น ให้คูณพลังงานด้วย น้ำหนักจริง ÷ 70)
- สูตรพลังงานสุทธิ: `kcal = (MET − 1) × 3.5 × น้ำหนักตัว(kg) ÷ 200 × T(นาที)` เมื่อ T = เวลารวมทั้งเซสชัน (รวมช่วงพัก)
- ที่ 70 กก. อัตราต่อนาทีเท่ากับ `(MET − 1) × 1.225` kcal/นาที (MET 2.8 → 2.205 · 3.5 → 3.063 · 3.8 → 3.430 · 5.0 → 4.900 · 6.0 → 6.125 · 8.0 → 8.575)
- ท่าที่ใช้ (ยืนยันจาก `weight_exercises` แล้ว): Leg Extension (`wet_id` 30, แรงต้าน·Isolation) · Back Squat (26, แรงต้าน·Compound) · Bench Press (1) · Dumbbell Curl (20) · Pull-up (8) · Dips (25) · Crunch (45) · Plank (34) · Hanging Leg Raise (35) — 3 ท่าหลังเป็นท่าหน้าท้อง แมปเป็น Isolation

## 3. ทดสอบด้วยมือผ่านแอปจริง

**ข้อจำกัดของหน้าจอแอป:** แอปแสดงเฉพาะพลังงานรวมที่ปัดเป็นจำนวนเต็มหลังบันทึก ("เผาผลาญ N kcal") และในหน้ารายละเอียด "N kcal · ระดับ…" — **ไม่แสดงค่า MET** จึงตรวจ MET ผ่านพลังงานที่เก็บใน DB (ข้อ 4) เวลารวม T และเวลาพักจริงนับจากนาฬิกาในแอป คุมได้แค่ประมาณ จึงเลือกค่าให้ห่างจากขอบ (30/60/90 วิ และ Reps 8) อย่างน้อย 10–15 วินาที

**วิธีใช้แอปให้ถูก**
1. เซตที่ 1–2 ต้องกด "พัก" หลังจบเซตแล้วรอตามเวลาที่ระบุ จึงกด "จบการพัก" (เวลาพักที่เก็บ = ช่วงนี้) — ถ้าไม่กดพัก แอปส่งเวลาพัก 0 วินาที ซึ่งจะทำให้ท่าน้ำหนักตัวได้ MET 8.0
2. เซตสุดท้าย: กรอกแล้วบันทึกเลย ไม่ต้องรอ (แอปส่งเวลาพักเซตสุดท้ายเป็น NULL)
3. ท่าน้ำหนักตัว (Pull-up, Crunch, Plank) ใส่น้ำหนักที่ยก 0
4. ตั้งน้ำหนักตัวของบัญชีให้รู้ค่าก่อน (สูตรใช้น้ำหนักตัวล่าสุดของสมาชิก) — ตารางข้างล่างไม่ระบุน้ำหนักที่ยก เพราะไม่มีผลต่อพลังงาน (ยกเว้น P12)

## 4. คำสั่งตรวจผลหลังทดสอบในแอป (รันใน MySQL)

คอลัมน์ `implied_final_met` คือ MET ที่ย้อนกลับจากพลังงานที่เก็บจริง ควรตรงกับ "Session MET ที่ควรได้" (คลาดเคลื่อนได้เล็กน้อยจากการปัดเศษ) · `rests` ควรมีเซตสุดท้ายเป็น `NULL` · `intensity` 1=เบา 2=กลาง 3=หนัก

```sql
SET @mb = <mb_id ของบัญชีที่ทดสอบ>;
SET @kg = (SELECT mbs_weight FROM member_body_stats WHERE mb_id = @mb ORDER BY mbs_recorded_date DESC, mbs_id DESC LIMIT 1);
SELECT MAX(r.wtrs_id) AS last_id, e.wet_name, r.wtrs_date, r.wtrs_duration AS T_sec, COUNT(*) AS sets,
       GROUP_CONCAT(r.wtrs_reps ORDER BY r.wtrs_set_no) AS reps,
       GROUP_CONCAT(IFNULL(r.wtrs_rest_seconds,'NULL') ORDER BY r.wtrs_set_no) AS rests,
       ROUND(SUM(r.wtrs_calories),2) AS kcal_saved,
       ROUND(1 + SUM(r.wtrs_calories) / ((r.wtrs_duration/60) * 0.0175 * @kg), 2) AS implied_final_met,
       MAX(r.wtrs_intensity_level) AS intensity
FROM weight_training_result r JOIN weight_exercises e ON e.wet_id = r.wet_id
WHERE r.mb_id = @mb
GROUP BY r.wet_id, r.wtrs_date, r.wtrs_duration
ORDER BY last_id DESC LIMIT 5;
```

(ค่าคงที่ 0.0175 = 3.5 ÷ 200 · ใช้ได้กับเซสชันที่บันทึกตั้งแต่ 2026-09-19 เพราะสูตรพลังงานเปลี่ยนวันนั้น)
