# ตรวจค่า METs (คาร์ดิโอ + เวทเทรนนิ่ง) เทียบ Compendium of Physical Activities 2011

- **แหล่งอ้างอิง:** Compendium of Physical Activities 2011 ฉบับแปลไทย (แปลโดย ดร.ชุติมา ชลายนเดชะ คณะกายภาพบำบัด ม.มหิดล) — ตรงกับ "Ainsworth et al., 2554" ที่บทที่ 2 ข้อ 2.1.4.10 และ 2.1.4.12 อ้าง (พ.ศ. 2554 = ค.ศ. 2011)
- **ไฟล์ต้นฉบับ:** [references/compendium-pa_thai-version-dr.-chutima.pdf](references/compendium-pa_thai-version-dr.-chutima.pdf) (24 หน้า)
- **ตารางที่ตรวจ:** ส่วนคาร์ดิโอ = `cardio.cdo_mets` ใน `food_and_fit_db` (query จริง 2026-09-19) · ส่วนเวทเทรนนิ่ง = ตาราง Dynamic METs Logic Matrix ในบทที่ 2 ข้อ 2.1.4.12 (ไม่เก็บใน DB — ค่าอยู่ในโค้ด `backend/services/calculator.go`)
- **กติกา:** ทุกครั้งที่เพิ่ม/แก้ค่า METs ต้องเทียบรหัสกับ Compendium ฉบับนี้ก่อน (`../CLAUDE.md` ข้อ 7[B] — ต้องตรวจสอบย้อนกลับได้ ห้ามเดา)
- **ข้อจำกัดการอ่าน PDF:** เครื่องมือสกัดข้อความ (pdftotext) ได้เฉพาะรหัสและตัวเลข METs ส่วนชื่อกิจกรรมภาษาไทยสกัดไม่ออก (ฟอนต์ไม่มีตารางแปลงตัวอักษร) — แถวที่มีเครื่องหมาย † ในตารางเวทด้านล่างยืนยันแล้วเฉพาะ **รหัส + ค่า METs** ชื่อกิจกรรมยังต้องเปิดดูหน้า PDF เทียบเองก่อนอ้างในเล่ม
